## 📋 Quick Start

### 1. Configure Database (2 minutes)
```bash
# Create .env.local with your Supabase connection
DATABASE_URL="postgresql://user:password@host:port/database"
```

### 2. Initialize Database (2 minutes)
```bash
npm run prisma:migrate    # Create tables
npm run prisma:seed       # Add products
```

### 3. Start Application (1 minute)
```bash
npm run dev               # http://localhost:3000
```

### 4. Test Features (10 minutes)
- Try importing stock
- Try exporting stock
- View statistics
- Export to Excel

## 📊 What's Inside Each File

### Pages
- **Home** - Landing page with feature cards
- **Import** - Multi-row form for adding stock
- **Export** - Multi-row form for removing stock
- **Statistics** - 4 tabs for analytics (4 tabs)

### Components
- **Navbar** - Fixed navigation with active indicators
- **FormRow** - Reusable form row component
- **CoffeeInTable** - Import history display
- **CoffeeOutTable** - Export history display
- **InventoryTable** - Current stock display
- **LoadingSkeleton** - Loading animation

### Server Actions
- `createCoffeeIn()` - Save imports with transactions
- `createCoffeeOut()` - Save exports with validation
- `getCoffeeInHistory()` - Retrieve import records
- `getCoffeeOutHistory()` - Retrieve export records
- `getCurrentInventory()` - Get current stock
- `getMonthlyTimeSeries()` - Analytics data
- All with filtering, validation, error handling

### Database
- **CoffeeQuantity** - Current stock levels
- **CoffeeIn** - Import records
- **CoffeeOut** - Export records
- With proper relationships and indexes
